# BTE Build Sessions practice repo

Welcome. This repository is where BTE Build Sessions participants practise the GitHub contribution flow on real, friendly content. The files here are real BTE session material: an about page, an FAQ, a glossary and a chapter list. Improve any of them and your improvement ships.

If you spot a mistke in any file, that is a real issue. Fix it, or open an issue so someone else can.

## What is in here

- `CONTRIBUTING.md` tells you exactly how to contribute. Read it first.
- `content/about-bte.md` says what BTE is.
- `content/faq.md` answers the questions new participants ask.
- `content/glossary.md` defines the words used across these files.
- `.github/` holds the issue and pull request templates.

## How to contribute

1. Read `CONTRIBUTING.md`.
2. Pick an open issue, ideally one labelled `good first issue`.
3. Comment on it to claim it. One issue, one owner.
4. Open a pull request against `dev`, following the steps in `CONTRIBUTING.md`.

## This session

During Session 01 you will open your first pull request here. A human will review it, and it merges when it passes. When you are comfortable with the flow, the real platform repo (bte-campus-app) uses the same rules with automated checks on top. The open issues labelled `good first issue` never run out, so keep going after the session.
