# Glossary

Every term used in the README and CONTRIBUTING files appears in this glossary. If a term is missing, that is a good first issue.

## Repository

A project folder, tracked by git and hosted on GitHub. Often shortened to "repo".

## Commit

A saved step on a branch, with a message that says what changed and why.

## Branch

A copy of the project where you work without touching the main copy.

## Pull request

Your proposal to merge your branch into the project, opened on GitHub for review.

## Issue

A tracked task or bug report. The repo's open issues are the to-do list.

## Review

A human reading your diff before it merges, approving it or leaving comments.

## Merge

Accepting a branch's changes into the target branch.

## Markdown

The light text format used for the files in this repo. Headings start with `#`, bold text sits between `**` and `**`, and lists start with a dash.
