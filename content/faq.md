# Frequently asked questions

Answers to the five questions below. If yours is not here, ask a helper at any build session, or open an issue.

## What is a repository?

A repository, often shortened to "repo", is a project folder tracked by git and hosted on GitHub. The repositry for this session is called `bte-build-sessions`.

## What is a fork?

A fork is your own copy of a repository on GitHub, under your account. You can write to your fork freely. Changes reach the original repo through a pull request.

## How do I claim an issue?

Comment on the issue with "I will take this one." The first claim wins. One issue, one owner.

## What happens after I open a pull request?

A human reviews your diff. If it passes, it merges into `dev`. If there are comments, you push fixes to the same branch and the pull request updates. You do not merge your own pull request.
